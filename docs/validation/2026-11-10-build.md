The amd64 ISO passed BIOS and UEFI live boot and a clean UEFI installation.
The approved ProductCode USB passed a full direct read-back of the written image
on 2026-11-10 at 23:48 UTC.

Earlier images exposed a Casper overlay startup failure and Calamares failures
in Wayland launch, automatic partitioning and the cleanup module. The delivered
ISO includes fixes for all four and passed the corresponding boot and install
flows.

## USB delivery

The first write stopped when buffered device writes exhausted the container's
256 MiB memory budget. The helper was updated to use direct writes and retained
its device, flush and read-back checks. The full retry succeeded. It verified all
2,156,703,744 bytes against the tested ISO's SHA-256.
[First attempt](../../output/live-v3/usb-write.json) ·
[Successful write and read-back](../../output/live-v3/usb-write-verified.json)

## Preview scope

Hardware boot remains to be tried on the laptop. Secure Boot and encrypted
installation are outside this preview. Installation validation covers a blank
virtual disk. The live boot menu offers a temporary Try DesOS session.
